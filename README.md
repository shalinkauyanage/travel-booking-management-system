# 🌍 GlobeTrek Travel Booking Management System

A web-based travel booking management system developed to manage travel packages, customer bookings, users, and administrative operations.

## 📌 Project Overview

GlobeTrek provides a centralized platform for managing travel-related activities.

The system allows customers to view travel packages and make bookings, while administrators and staff can manage packages, bookings, users, and other travel-related information.

## ✨ Features

- 🧳 Travel Package Management
- 📅 Travel Booking Management
- 👤 User Registration and Login
- 🔐 User Authentication
- 🛠️ Admin Dashboard
- 👥 Customer Management
- 📦 Package Management
- 📋 Booking Management
- 📩 Contact Management
- 🖼️ Travel Destination Images
- 🗄️ MySQL Database Integration

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/shalinkauyanage/travel-booking-management-system.git
```

### 2. Set Up the Project

Place the project inside your local WAMP web server directory.

For example:

```text
C:\wamp64\www\
```

### 3. Set Up the Database

1. Start the WAMP server.
2. Make sure Apache and MySQL are running.
3. Open phpMyAdmin.
4. Create the required MySQL database.
5. Import the `globetrek.sql` file.
6. Check and update the database connection settings if required.

### 4. Run the Application

After starting Apache and MySQL, open the application through your local server:

```text
http://localhost/travel-booking-management-system/
```
